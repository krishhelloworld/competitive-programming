# *2-D KADANE*-; 
1. Transpose if rows > cols
2. Fix top
3. Reset compressed[]
4. Move bottom downward
5. Add current row into compressed[]
6. Run 1D Kadane
7. Update global answer

┌────┬────┬────┬────┬─────┐
│  1 │  2 │ -1 │ -4 │ -20 │
├────┼────┼────┼────┼─────┤
│ -8 │ -3 │  4 │  2 │   1 │
├────┼────┼────┼────┼─────┤
│  3 │  8 │ 10 │  1 │   3 │
├────┼────┼────┼────┼─────┤
│ -4 │ -1 │  1 │  7 │  -6 │
└────┴────┴────┴────┴─────┘
---------------------------------------------------------

For example, if:

- top = 1
- bottom = 3

- [ ] we are considering:

```
r1
┌────┬────┬────┬────┬────┐
│ -8 │ -3 │  4 │  2 │  1 │
└────┴────┴────┴────┴────┘

r2
┌────┬────┬────┬────┬────┐
│  3 │  8 │ 10 │  1 │  3 │
└────┴────┴────┴────┴────┘

r3
┌────┬────┬────┬────┬────┐
│ -4 │ -1 │  1 │  7 │ -6 │
└────┴────┴────┴────┴────┘
```

We add vertically:
--------------------------
>column 0: -8 + 3 + (-4) = -9
>column 1: -3 + 8 + (-1) = 4
>column 2:  4 + 10 + 1 = 15
>column 3:  2 + 1 + 7 = 10
>column 4:  1 + 3 + (-6) = -2
--------------------------------
So the 2D problem becomes a 1D problem:

compressed = [-9, 4, 15, 10, -2]

Now we simply run Kadane's algorithm on this array.
